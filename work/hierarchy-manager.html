Hierarchy Manager web app

Financial rollup trees changing faster than reports could follow.

Problem

Financial rollup trees changing faster than reports could follow.

Approach

Architected, deployed, and project-managed the Hierarchy Manager web application: a Snowflake-based tool for creating, mapping, and comparing multi-level financial structures. Led the technical architecture and deployment strategy specifically for financial hierarchy management and schema comparison - the structures that determine how every dollar rolls up in reporting. Versioned, comparable, and consistent across the reporting estate.

Architecture

Financial hierarchies are code, not config

When a cost-center tree changes, every financial report changes with it. Treating hierarchies as governed, versioned objects on the platform - instead of a spreadsheet on someone's desktop - is the difference between a controlled reorg and a quarter of unexplainable variances.

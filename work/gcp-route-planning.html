Problem

Production architecture on the third cloud.

Approach

Designed and deployed the cloud architecture for a route-planning application on Google Cloud Platform for a technology client. Owned the architecture and deployment approach - compute, networking, and delivery - completing the multi-cloud picture: production architecture work delivered on GCP alongside deep Azure and AWS estates. Different cloud, same discipline: design for the workload, deploy repeatably, keep the bill predictable.

Architecture

Third cloud, same principles

Multi-cloud competence isn't knowing three consoles - it's carrying the same architectural discipline across them. This GCP engagement applied identical patterns proven on Azure and AWS: infrastructure as repeatable deployment, security by default, cost as a design input.

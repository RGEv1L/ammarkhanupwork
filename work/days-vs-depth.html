Problem

The drilling curve everyone watches, rebuilt on governed data.

Approach

Developed and provided oversight for daily drilling report development over Snowflake using WellView source data, centered on days-vs-depth reporting - the curve every drilling engineer reads first. Aligned WellView source data with Snowflake-based reporting outputs while maintaining consistency with the operator's overall reporting architecture, so drilling performance reporting shared the same governed foundations as everything else.

Architecture

The drilling curve everyone watches

Days vs. depth is how drilling performance is judged: are we ahead of the curve or burning AFE? Getting it right means reconciling operational WellView data into the governed platform daily - reporting that operations trusts because it ties to source.
